投屏到电视

电脑 / 手机与电视在同一个 WiFi 下，可把正在播放的内容推到电视（DLNA）。

离线下载

在详情页点「缓存」，勾选要存的集数，就能把剧存到本机，没网也能看。缓存期间请让独享库停在前台（手机切到后台会被系统暂停）。

本机缓存

片单和封面会自动在本机存一份，打开就能秒出内容；完全断网时也能翻已缓存的片单和封面。

影视源

内置采集站已自动配置；也可以添加自己的采集接口。所有源会自动合并成一份片单，不用手动挑源。

手机 / 平板连接

在手机上装好「独享库」后，把下面这个地址填到手机的「我的 → 手机 / 平板连接」里（手机和电脑要连同一个 WiFi）。

可选：连上电脑后可以投屏到电视、播放电脑上的本地文件。不连也能正常看片。

自定义播放地址

支持 m3u8 / mp4 / flv / ts 直链，也可以把本地文件拖到下面的输入框。

· 直播地址通常形如 http://ip:port/live/xxx.m3u8
· 本地文件请填写完整路径，例如 D:\影视\流浪地球.mkv

直播源

粘贴 m3u / m3u8 直播列表地址（如 IPTV 订阅地址），或直接粘贴单条直播流地址。
